# Security Policy

## Supported Versions

We try to keep the API-Surface clean. So we only support the latest version.

## What we consider to be no Vulnerability
1. False positive detections. Developers should ask the user if the detected hosts are correct.
2. Calls to intternal ressources etc. Developers have to sanetice emails put into this libary if needed!

## Reporting a Vulnerability

You can contact us at security@accountdesk.de
